| Документ | Для чего |
| --- | --- |
| [ARCHITECTURE.md](ARCHITECTURE.md) | Клиент, серверы, authoritative границы, сетевые и desktop-потоки |
| [DEVELOPMENT.md](DEVELOPMENT.md) | Окружение, локальный запуск, сборки и обязательные проверки |
| [COMBAT_AI.md](COMBAT_AI.md) | Архетипы, уровни 1–40, телеграфы и настройка NPC |
| [RELEASES.md](RELEASES.md) | Windows artifacts, GitHub Release и проверяемые web patches |
| [../server/README.md](../server/README.md) | Rust world server, CLI, протокол и Linux deployment |

Краткий старт, управление и карта файлов находятся в [корневом README](../README.md).
